---
title: Suggestions
description: "Members suggest things, everyone votes, staff mark the outcome."
---

`/suggest` posts a suggestion with voting buttons. One vote per member — changing
your mind updates your vote rather than stacking another one, so the count is always
the real count.

Staff mark each one accepted, denied or implemented, with a reason.

Free servers get a limited number of open suggestions; Pro is unlimited.

## Commands

### `/suggest`

Suggest something for the server

### `/suggestion`

Manage suggestions

| Subcommand | What it does |
| --- | --- |
| `/suggestion status` | Set the status of a suggestion |
| `/suggestion list` | List suggestions |
