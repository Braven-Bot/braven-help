<Callout>This is a **Elite** feature. `/subscribe` to enable it.</Callout>

Set an accent colour and footer used across every embed Braven sends, so it looks
like part of your server rather than a third-party bot.

Individual [panels](/docs/tickets/panels) can override the colour, which is how one
panel can look different without losing branding everywhere else.

`/embed` builds a standalone embed — announcements, rules, anything — using the same
builder. That one is free on every plan.

## Commands

### `/branding`

Match Braven’s embeds to your server

| Subcommand | What it does |
| --- | --- |
| `/branding colour` | Set the colour on every embed Braven posts |
| `/branding footer` | Set the footer on every embed Braven posts |
| `/branding reset` | Go back to the defaults |
| `/branding show` | Show the current branding |

### `/embed`

Build a message embed

| Subcommand | What it does |
| --- | --- |
| `/embed generate` | Build an embed and post it |
| `/embed edit` | Edit an embed Braven posted in this channel |
