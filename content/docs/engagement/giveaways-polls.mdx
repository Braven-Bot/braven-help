---
title: Giveaways and polls
description: "Run a giveaway with role requirements, or ask the community."
---

**Polls** are free. `/poll` asks a question with up to 25 options and live results.
One vote per member, changeable.

**Giveaways** are Pro. Set a duration, a number of winners, and optionally require a
role to enter or give boosters bonus entries. Braven draws automatically when it
ends, and can reroll if a winner does not claim.

## Commands

### `/giveaway`

Run a giveaway

| Subcommand | What it does |
| --- | --- |
| `/giveaway start` | Start a giveaway |
| `/giveaway end` | End a giveaway early and draw the winners |
| `/giveaway reroll` | Draw new winners, excluding the previous ones |
| `/giveaway list` | Show running giveaways |

### `/poll`

Ask the community

| Subcommand | What it does |
| --- | --- |
| `/poll start` | Start a poll |
| `/poll end` | Close a poll and show the result |
